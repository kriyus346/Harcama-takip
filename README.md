Harcama Takip Uygulaması (Ionic & Angular)
Bu proje, mobil programlama dersi kapsamında geliştirilmiş bir Harcama Takip uygulamasıdır. Kullanıcıların günlük harcamalarını kolayca kaydedebilmesi, listelemesi ve toplam bakiyelerini takip edebilmesi amacıyla tasarlanmıştır.

🚀 Özellikler
Harcama Ekleme: Harcama adı ve tutar girilerek listeye yeni öğeler eklenebilir.

Dinamik Listeleme: Eklenen tüm harcamalar ana ekranda liste şeklinde görüntülenir.

Harcama Silme: Listeden istenilen harcama tek tıkla kaldırılabilir.

Otomatik Hesaplama: Harcamalar eklendikçe veya silindikçe toplam tutar anlık olarak güncellenir.

🛠 Kullanılan Teknolojiler
Framework: Ionic Framework

Dil: TypeScript & HTML/CSS

Platform: Angular tabanlı Web/Mobil

💻 Kurulum ve Çalıştırma
Projeyi yerel makinenizde çalıştırmak için:

Projeyi indirin.

Terminalde proje klasörüne gidin.

Gerekli paketleri yüklemek için: npm install

Uygulamayı ayağa kaldırmak için: ionic serve
